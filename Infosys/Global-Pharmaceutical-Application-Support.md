
# Global Pharmaceutical Organisation – Enterprise Application Support

**Organisation:** Infosys Limited  
**Role:** Senior Systems Engineer – Application Support  
**Period:** August 2015 – July 2017  
**Project Area:** Enterprise Application Support and Document Management

## Project Overview

Provided application support for enterprise document management systems used within a global pharmaceutical organisation. The work involved application monitoring, technical troubleshooting, document-related operations and maintaining production stability.

## My Contributions

- Provided application support for enterprise document management applications.
- Automated monitoring of critical file transfers using Python scripts.
- Performed SQL-based troubleshooting to investigate application and data-related issues.
- Conducted root cause analysis and supported the resolution of production issues.
- Generated operational reports to support application monitoring and reporting activities.
- Supported the process of adding client records to the application.
- Performed document watermarking and supported document version checks.
- Helped maintain document accuracy and consistency across application workflows.
